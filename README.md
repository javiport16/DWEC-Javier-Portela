# Juego de misiones - Práctica Unidad 3

Proyecto de la asignatura **Desarrollo web en entorno cliente (Unidad 3)**.

Juego sencillo en el que el usuario introduce sus datos y completa pequeñas misiones, usando JavaScript para manipular el navegador, el almacenamiento y la interacción con el usuario.

## Requisitos del enunciado

1. **Perfil de jugador**: nombre y fecha de nacimiento (válida, anterior a hoy y con edad mínima). Si no son correctos, se muestra "Acceso denegado".
2. **Personalización del entorno**: panel con el nombre formateado (métodos de `String`), edad calculada (métodos de `Date`) y cambios de estilo según los datos.
3. **Interacción y puntuación**: eventos `click`, números aleatorios, redondeo, otra función de `Number`/`Math` y uso de arrays.
4. **Ventana adicional**: ventana que recibe información del usuario (pistas, puntuación, misiones...).
5. **Almacenamiento**: uso de cookies, `sessionStorage` y `localStorage`.
6. **Carga del script**: script en el `head` con los eventos necesarios.
